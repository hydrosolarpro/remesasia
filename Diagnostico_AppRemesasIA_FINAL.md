# DIAGNÓSTICO DE PRODUCTO — App Remesas IA
**Versión:** FINAL · **Canal:** 02 — SaaS Preestablecido para PyMEs  
**Cliente:** Remesas — Operador de transferencias PEN → VES  
**Corredor:** Soles Peruanos (PEN) → USDT (Binance/El Dorado) → Bolívares Soberanos (VES)  
**Actores:** Cliente Final (Perú) | Operador Perú (1–2 personas) | Operador Venezuela  
**Pagos Perú:** Yape / Transferencia Bancaria con comprobación de fondos  
**Fecha:** Julio 2026  
**Autor:** Hermes Agents — Diagnóstico IA · Pipeline Automatización SaaS

---

## 1. RESUMEN EJECUTIVO

App Remesas IA conecta a clientes finales en Perú con el Operador Perú reemplazando WhatsApp por una app móvil. El cliente calcula, solicita y paga por Yape o transferencia bancaria subiendo su comprobante. El Operador Perú verifica los fondos con un toque y coordina con el Operador Venezuela dentro de la misma app. El Operador Venezuela ejecuta la transferencia bancaria al beneficiario final. Un dashboard financiero totaliza transferencias y ganancias en tiempo real (diario / mensual / anual). El mercado objetivo es de 1.54 millones de venezolanos en Perú, con remesas estimadas de $4M USD/mes en el corredor PEN→VES y cero competidores digitales en ese corredor específico.

## 2. ESTUDIO DE MERCADO

### 2.1 Mercado Global de Remesas

| Indicador | Dato / Fuente |
|---|---|
| Volumen global 2023 | $857,000 millones USD enviados a países de renta baja y media (Banco Mundial, 2023) |
| Crecimiento proyectado | CAGR 5.8% anual hasta 2030. Impulsado por migración y digitalización |
| Canales digitales | 47% de las remesas globales ya se envían por canales digitales (vs. 15% en 2017). Tendencia irreversible |
| Costo promedio | 6.2% del monto enviado (ONU meta: <3%). Apps digitales ya bajan al 2–3% |

### 2.2 Corredor América Latina — Diáspora Venezolana

| Indicador | Dato / Fuente |
|---|---|
| Diáspora venezolana | 7.7 millones de venezolanos en el exterior (ACNUR 2023). Mayor éxodo de América Latina |
| Venezolanos en Perú | 1.54 millones registrados (Superintendencia de Migraciones, 2023). 2° destino de la diáspora |
| Remesas Venezuela 2023 | $3,400 millones USD recibidos (BCV / estimaciones). Principal fuente de divisas de hogares venezolanos |
| Frecuencia de envío | 71% de la diáspora venezolana envía dinero al menos 1 vez al mes (encuesta Remesas Latam 2022) |
| Ticket promedio PEN→VES | S/ 100 – S/ 800 por operación (estimación operadores informales corredor Perú–Venezuela) |

### 2.3 Mercado Directo — Corredor Perú → Venezuela (TAM / SAM / SOM)

| Indicador | Estimación / Dato |
|---|---|
| Población objetivo | 1.54M venezolanos en Perú. ~600,000 económicamente activos con ingresos regulares |
| Frecuencia estimada | Si solo el 10% envía 1 vez/mes: 60,000 transacciones/mes en el corredor PEN→VES |
| Volumen estimado (conservador) | 60,000 tx × S/250 promedio = S/15,000,000/mes en el corredor ≈ $4M USD/mes |
| Operadores informales activos | Decenas de operadores WhatsApp activos en Perú. Mercado atomizado, sin solución digital dominante |
| Oportunidad de captura | Una app que digitalice puede capturar múltiples operadores como clientes SaaS (Canal 02 escalado) |

### 2.4 Análisis de Competencia

| Competidor | Posición vs. App Remesas IA |
|---|---|
| Western Union / MoneyGram | No ofrecen envío directo a Venezuela de forma masiva. Restricciones regulatorias. Costo 7–9%. Fuera del alcance del usuario promedio |
| Binance P2P / El Dorado | Son el puente USDT que usa el operador, no el producto final para el cliente. El cliente no puede usarlos sin conocimiento cripto. Brecha que la app cubre |
| Remesadoras tradicionales (Rapi, La Nacional) | Operan en corredores USD, no PEN→VES. Sin presencia en el corredor específico |
| Grupos WhatsApp / Telegram de operadores | Competencia directa actual. Sin app, sin comprobante, sin trazabilidad. Ventaja: familiaridad. Desventaja: todo lo demás |
| Apps de remesas digitales (Remitly, Wise) | No cubren Venezuela como destino por restricciones regulatorias. Mercado libre para operadores informales |
| **Competidores directos con app** | **NINGUNO identificado con app nativa para el corredor PEN→VES en el mercado informal peruano. VENTANA DE OPORTUNIDAD ABIERTA** |

### 2.5 Oportunidad de Negocio SaaS

- Remesas es el primer operador en tener una app nativa para este corredor → **ventaja de primer movedor**
- El mismo producto puede licenciarse a otros operadores del corredor PEN→VES (modelo SaaS Canal 02): cada operador con su app white-label y su tasa
- Expansión a corredores adyacentes: CLP→VES (Chile), ARS→VES (Argentina), USD→VES (EE.UU.) con el mismo stack
- Potencial de agregar programa de referidos: cliente refiere a otro venezolano, ambos obtienen descuento en la siguiente operación
- Regulación futura como oportunidad: app profesional posiciona al operador para obtener licencias formales de cambio

### 2.6 Modelo de Ingresos Proyectado

| Fuente de Ingreso | Descripción |
|---|---|
| Spread de tasa (modelo actual) | Diferencia entre tasa publicada al cliente y tasa real de compra USDT. ~2–5% por operación. Núcleo del negocio |
| Comisión fija por operación (V2) | S/3–8 por transacción además del spread. Común en remesadoras formales |
| Licencia SaaS a otros operadores (V2) | S/299–599/mes por usar la plataforma white-label |
| Premium cliente (V3) | Envío exprés <30 min a costo adicional de S/5–10 por operación |

### 2.7 Proyección de Crecimiento por Fases

## 5. ESTADOS DEL CICLO DE VIDA DE UNA SOLICITUD

```
BORRADOR → PENDIENTE → EN VERIFICACIÓN → FONDOS VERIFICADOS → EN PROCESO → COMPLETADA
                                └─────────────────────────────────────────── RECHAZADA
                                                                              CANCELADA
```

| Estado | Descripción |
|---|---|
| BORRADOR | Cliente llenando el formulario |
| PENDIENTE | Solicitud enviada, cliente aún no sube comprobante |
| EN VERIFICACIÓN | Comprobante subido — Operador Perú debe revisar |
| FONDOS VERIFICADOS | Operador Perú aprobó — iniciando conversión USDT |
| EN PROCESO | USDT enviados — Operador Venezuela ejecutando |
| COMPLETADA | Transferencia VES realizada — comprobante generado |
| RECHAZADA | Comprobante inválido o monto no coincide |
| CANCELADA | Cancelada por cliente u operador |

## 7. MÓDULO DASHBOARD FINANCIERO

### Componentes

| Vista / Componente | Datos que muestra |
|---|---|
| Tarjetas KPI tiempo real | Total transferencias día \| Soles operados \| USDT movilizados \| Ganancia del día |
| Ganancia por operación | Spread = tasa cliente − tasa real Binance. En Soles y % por operación |
| Resumen diario | N° completadas / rechazadas / canceladas. Volumen total PEN/USDT/VES. Ganancia neta |
| Resumen mensual | Acumulado semanal. Días de mayor volumen. Op. de mayor y menor margen |
| Resumen anual | Mes a mes. Tendencia de crecimiento. Total ganancias del año |
| Exportación | CSV (Excel/Sheets) o PDF resumen ejecutivo por período |
| Detalle por operación | ID, fecha/hora, cliente, monto PEN, tasas, USDT, Bs entregados, ganancia, estado |

### Lógica de Cálculo de Ganancia

- **Ganancia por operación** = (Tasa publicada al cliente − Tasa real de compra Binance/El Dorado) × Monto USDT
- El operador registra la tasa real al marcar "USDT enviado". El dashboard calcula el spread automáticamente
- Totales: ganancia acumulada del día / mes en curso / año. Promedio de ganancia por operación

## 8. MÓDULO DE VERIFICACIÓN DE FONDOS

### Flujo por método de pago

| Paso | Yape | Transferencia Bancaria |
|---|---|---|
| 1 — Cliente paga | Transfiere al número Yape del operador (visible en la app) | Transfiere al CCI/cuenta del operador (visible en la app) |
| 2 — Sube comprobante | Screenshot de pantalla Yape → sube desde la app | Voucher bancario (app banco, SMS o email) → sube desde la app |
| 3 — Notificación | Push al Operador Perú: "Nueva solicitud con comprobante" | Push al Operador Perú: "Nueva solicitud con comprobante" |
| 4 — Revisión MVP | Operador ve imagen: verifica nombre, monto, fecha → Aprueba/Rechaza con motivo | Operador ve voucher: verifica N° operación, monto, banco → Aprueba/Rechaza |
| 5 — V2 OCR | Google Vision extrae monto/fecha del screenshot Yape. Alerta si no coincide | OCR sobre voucher bancario. Extrae monto, banco, fecha. Validación automática |
| 6 — Resultado | Estado → FONDOS VERIFICADOS. Push de confirmación al cliente | Estado → FONDOS VERIFICADOS. Push de confirmación al cliente |

## 9. BREAKDOWN TÉCNICO — INSUMO PARA CLAUDE

| Capa | Decisión Técnica |
|---|---|
| App Móvil (3 roles) | React Native + Expo. iOS y Android desde un código. 3 roles: Cliente / Op. Perú / Op. VZ |
| Backend / BD | Supabase — PostgreSQL + Row Level Security (RLS) por rol + Realtime para sincronización de estado entre actores |
| Autenticación | Supabase Auth — SMS OTP por número de teléfono. Rol asignado por Operador Perú al dar de alta usuarios |
| Verificación fondos | MVP: revisión manual de imagen por el operador. V2: OCR automático (Google Vision API) |
| Notificaciones Push | Firebase Cloud Messaging (FCM). Disparado por Supabase DB Webhooks → Edge Function → FCM |
| Comprobantes PDF | Supabase Edge Functions (Node.js + PDFKit). Almacenados en Supabase Storage. URL firmada descargable |
| Dashboard | Vistas materializadas PostgreSQL para totales por día/mes/año. Gráficas con Victory Native (RN) / Recharts (web) |
| Subida imágenes | React Native Image Picker → Supabase Storage. Vista directa en panel del operador |
| Panel web Op. | React + Vite desplegado en Vercel. Para operadores que prefieran computadora |
| Despliegue | EAS Build (Expo Application Services) para iOS/Android. Vercel para panel web. Supabase Cloud para backend |
| V2 — Integraciones | Binance API / El Dorado API (tasa USDT automática). OCR Google Vision. Culqi/Niubiz (pagos PEN online) |

## 11. CANAL RECOMENDADO

**CANAL 02 — SaaS Preestablecido para PyMEs**

**Justificación:** El dolor de Remesas es específico de un operador PyME de servicios financieros con un flujo multi-actor (Perú + Venezuela) que requiere coordinación en tiempo real. El producto puede empaquetarse y replicarse para otros operadores del mismo corredor. No requiere integración con sistemas bancarios complejos en el MVP (Canal 03). No es consumo masivo B2C sin relación operativa (Canal 01).

**Ruta de evolución:** Canal 02 → Canal 03 si Remesas formaliza y necesita integrar APIs bancarias venezolanas, cumplimiento regulatorio o conectar automáticamente con Binance/El Dorado.

## 12. CASOS DE ÉXITO DE RESPALDO

**Remitly (EE.UU. → LATAM):** Digitalizó remesas internacionales con app móvil simple: monto → cálculo instantáneo → confirmación → tracking de estado. Resultado: +$1B en volumen anual, NPS superior a Western Union. Patrón UX directamente transferible al corredor PEN→VES.

**El Dorado (Colombia/Venezuela):** Exchange que Remesas ya usa para el puente USDT. Demuestra que el mercado PEN/COP→USDT→VES está validado digitalmente con paneles de operador, historial y comprobantes. La app replica esta transparencia de estado pero extendida al cliente final.

**Yapu / Nequi (Bolivia, Colombia):** Operadores informales adoptaron apps propias para salir de WhatsApp. Reducción del 70% en tiempo por operación y +40% en volumen diario sin agregar personal. Contexto idéntico: mercado latinoamericano, operadores 1–3 personas, clientes solo con smartphone.
